# Justin Portfolio

Single-page scrollytelling portfolio for Justin, built with Vite, React, Tailwind, Motion, Lenis, and react-three-fiber.

The visual reference came from Stitch project `9911666754708996787`, using the generated **Earth & Intellect** design system. The Stitch MCP surface in this session did not expose a literal `extract_design_context` tool, so the implementation uses the generated screen outputs and project design-system tokens as the extracted context.

## Run

```bash
npm install
npm run dev
```

## Replacing a Placeholder `.glb`

1. Export the model as glTF binary, using the `.glb` extension.
2. Keep materials matte and warm-toned where possible. Roughness should be high, metallic low.
3. Drop the file into `public/models/` using the same filename as the placeholder, or update the matching `modelPath` in `src/data/portfolio.ts`.
4. Add a matching fallback still image in `public/images/` and update `fallbackImage` if the filename changes.
5. Run:

```bash
npm test
npm run build
```

## Placeholder Generation

Phase 1 placeholder bitmaps, `.glb` primitives, and the resume placeholder are generated by:

```bash
node scripts/generate-placeholders.mjs
```

The generated files are intentionally replaceable. Layout code should not need to change when real assets arrive.
